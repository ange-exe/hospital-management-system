# Quick Start Guide

## Getting Started in 3 Steps

1. **Extract and Navigate**
   ```bash
   cd hospital-management-system
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Run the Application**
   ```bash
   npm run dev
   ```

The app will open at `http://localhost:5173`

## What You'll See

✅ **Home Page**: Welcome screen with feature cards and quick stats
✅ **Medical Records**: Sample patient data, visit history, and lab results
✅ **Appointments**: Booking form with upcoming appointments display
✅ **Maternal Care**: Pregnancy timeline and resources
✅ **Health Articles**: Filterable health content with research updates

## Key Features

- 📱 **Fully Responsive** - Works on all screen sizes
- 🎨 **Modern Design** - Professional healthcare aesthetic
- ⚡ **Fast Navigation** - Instant page switching with React
- 📝 **Interactive Forms** - Appointment scheduling UI
- 🎭 **Smooth Animations** - Polished user experience

## Notes

- All data is static (no backend required)
- Forms display success messages without actual submission
- Perfect for demonstration and prototyping

Enjoy exploring the Health Portal! 🏥
